# Secunda Web

Фронтенд для API управления задачами: React + TypeScript + Vite.

## Запуск

Поднимите API (`make up` или `make run` в корне репозитория), затем:

```bash
cd web
npm install
npm run dev
```

Приложение: <http://localhost:5173>

Vite проксирует `/api` на `http://127.0.0.1:8080`.

## Возможности

- регистрация и вход (JWT в `localStorage`);
- список и создание команд;
- приглашение участников по `user_id` (owner/admin);
- канбан-доска по статусам с drag-and-drop (смена статуса через API + `version`);
- быстрое создание карточки в колонке;
- панель задачи: редактирование, история, комментарии;
- SQL-статистика команды (owner/admin).
